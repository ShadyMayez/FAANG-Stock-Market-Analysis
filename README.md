# FAANG Stock Market Analysis

End-to-end financial analytics project covering **Meta, Apple, Amazon, Netflix, and Alphabet** with Python-based analysis, an interactive Streamlit experience, and Power BI business-intelligence reporting.

## Overview

This project combines quantitative market analysis with executive-style visualization. It explores historical price behavior, technical indicators, company fundamentals, risk-adjusted performance, and cross-company comparisons to support clearer investment analysis.

Rather than focusing only on charts, the project is structured around three questions:

1. How has each company performed over time?
2. How do valuation, profitability, growth, and risk compare across the group?
3. Which companies stand out under different investment criteria?

## What the Project Covers

### Market Performance

- Historical price and return analysis
- Trend identification
- Candlestick visualization
- Volatility and drawdown inspection
- Support and resistance analysis

### Technical Analysis

- RSI
- MACD
- Moving-average signals
- Price momentum
- Trading-pattern exploration

### Fundamental & Comparative Analysis

- P/E ratio
- EPS
- Net margin
- Return on equity
- Revenue growth
- Beta
- Sharpe ratio

### Decision-Oriented Reporting

- KPI summaries
- Side-by-side company comparisons
- Risk-versus-return interpretation
- Investment-screening logic
- Power BI storytelling for non-technical stakeholders

## Analytical Workflow

```text
Collect / load market data
        ↓
Clean and validate
        ↓
Calculate returns & indicators
        ↓
Analyze company-level performance
        ↓
Compare valuation, growth & risk
        ↓
Create interactive dashboards
        ↓
Translate findings into business insights
```

## Why This Project Matters

The project demonstrates the full data-analysis lifecycle rather than isolated notebook work: data preparation, metric design, visualization, comparative analysis, dashboard development, and communication of findings to a business audience.

It also shows how the same analytical dataset can be presented differently for technical exploration in Python and executive consumption in Power BI.
